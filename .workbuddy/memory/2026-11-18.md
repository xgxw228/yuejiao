## 环境重启后的恢复步骤（重要）
机器重启后 Docker 引擎和后端都停了，恢复顺序：
1. Docker Desktop 起来后等 `docker info` 能返回版本号，再 `cd /d/dify-1.10.0/docker && docker compose up -d`
2. **必须重启 nginx**：`docker restart docker-nginx-1`。api 容器被重建后 IP 变了，
   nginx 缓存旧 upstream 解析，不重启会一直 502。
3. 后端：`cd D:/项目1/backend && python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload`
4. 控制台 cookie 也会失效，需重新 POST /console/api/login 写 cookies.txt。

## 请假日期解析重写（services/leave_parser.py）
问题：「我要25号请假一天」被解析成明天，因为旧实现只认「11月25日/2026-11-25」，
单独的「25号」直接落到默认明天。

新实现分三层：
- `_try_parse_date()` 严格解析单个日期片段，解析不出返回 None（不再兜底）
- `_day_of_month(day, today, hint)` 处理只说了日子的情况：本月这天已过 或 本月没这天
  → 顺延到下月；支持「下个月5号」「这个月28号」；`_make_date` 处理跨年与月末溢出（31号）
- `_parse_explicit_range()` 用 `_DATE_TOKEN` 正则识别「25号到27号」「12月20日至12月22日」
  「下周一请假到周三」，结束日早于开始日时按同月/次月重落

注意：区间正则的分隔符不能包含裸 `-`，否则会把 `2026-12-20` 自身拆开导致 group 为 None。

## 登录页 + 角色权限（把"上帝视角"枚举改成真登录）

- student：只有留学管家，身份锁死本人
- parent：只有客服与活动助手（看不到学生隐私数据）
