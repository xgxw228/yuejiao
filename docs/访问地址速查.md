# 粤教服务系统 · 访问地址速查

> 全部地址于 2026-11-18 15:26 实测返回 200（`/v1` 类鉴权接口除外）。
> 后端：FastAPI :8000　Dify：Docker nginx :80　数据库：SQLite 文件

## 一、业务前端（FastAPI :8000）

| 地址 | 用途 | 权限 |
|---|---|---|
| http://127.0.0.1:8000/ | 登录页（根路径即登录，不是业务首页） | 公开 |
| http://127.0.0.1:8000/login | 登录页显式路径 | 公开 |
| http://127.0.0.1:8000/demo/ | 业务前端（登录后进，5 角色同一页面按权限渲染） | 需登录 |
| **http://127.0.0.1:8000/admin** | **只读数据后台**：12 张表、行数、关键字搜索、分页，隐藏 password_hash | admin / emp005（领导）；其余 403，未登录 401 |

> `/demo/` 是 `frontend/` 目录的静态挂载，`/admin` 是独立路由。
> `http://127.0.0.1:8000/demo/admin.html` 文件式也能打开，但规范入口是 `/admin`。

## 二、接口与文档（FastAPI :8000）

| 地址 | 用途 |
|---|---|
| http://127.0.0.1:8000/docs | Swagger UI，可直接试调 |
| http://127.0.0.1:8000/redoc | ReDoc，适合通读接口定义 |
| http://127.0.0.1:8000/openapi.json | 接口原始 schema（57 个路径），导 Postman / 生成客户端 |
| http://127.0.0.1:8000/api/health | 健康检查：db 连通、dify 连通、uptime |

## 三、Dify 控制台（localhost:80）

| 地址 | 用途 |
|---|---|
| http://localhost | 落地即跳 `/apps` |
| http://localhost/signin | 登录页 |
| http://localhost/apps | 三个 Agent（员工助手 / 客服与活动 / 留学生管家）：改提示词、发布工作流 |
| http://localhost/datasets | 知识库。**改 top_k 阈值必须在这里的数据集设置里改**，节点上的 top_k 不生效 |
| http://localhost/tools | 工具管理 |

> 容器端口：nginx `80/443` 对外；api/worker 的 `5001`、web 的 `3000`、db 的 `5432` 均未映射到宿主机，不可直连；
> `5003` 是 plugin daemon，非人工入口。

## 五、鉴权速记

- 页面调用：`Authorization: Bearer <token>`（登录后由前端携带）
- Dify HTTP 节点调用：`X-Internal-Token: yj-internal-demo-2026`
- 写操作无凭证一律 401；审批以 token 内身份为准，不能替他人审批
